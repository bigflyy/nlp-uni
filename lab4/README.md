# Лабораторная 4

[solver.py](solver.py) подбирает промпт без форм заданных слов и однокоренных слов,
после которого ruGPT-3 large сразу дописывает эти два слова в заданном порядке и форме.

## Установка и запуск

Проверено на Python 3.12.12, torch 2.12.1, transformers 4.57.6, pymorphy3 2.0.6.
Если эти пакеты уже стоят, устанавливать ничего не нужно.

```bash
python -m venv .venv
source .venv/Scripts/activate
python -m pip install -r requirements.txt
python solver.py вспугнуть спиной 6
```

Третий аргумент - сид, по умолчанию 1. Таблица корней читается из
`resources/roots.json.gz`, это копия таблицы из lab3. Модель `ai-forever/rugpt3large_based_on_gpt2`
(3.1 ГБ) скачивается при первом запуске в кэш Hugging Face. При доступной CUDA
программа использует видеокарту, иначе процессор.

## Пара по заданию: вспугнуть спиной

Промпт, дефис в начале - его часть:

```
- шапку трибуны трогать директору дам врасплох огород сны догнать лбом отказаться вид ключом километр обора картинки мелькнула пасть страшно оглядываясь переклад врасплох птиц
```

Проверка функцией `generate` из задания:

```python
generate(model, tok, prompt, do_sample=False, repetition_penalty=1.0,
         no_repeat_ngram_size=0, num_beams=1)
```

Модель пишет "вспугнуть спиной измерить взглядом измерить в уме". `num_beams=1`
обязателен: со значением `None` transformers 4.57.6 падает с `TypeError`.
